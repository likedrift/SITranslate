# 思译 · Si Translate

一个轻量的 Chrome Manifest V3 扩展。用你选择的大模型翻译整页、选中文字或视频字幕，保留页面功能，并可恢复原文。

## 安装与首次配置

已经构建好的扩展在本项目的 `dist` 文件夹，安装无需 Node.js 或其他开发工具。

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 `D:\haru_ws\si_translate\dist`。
4. 在工具栏固定「思译」，点击扩展，再点击设置按钮。
5. 默认提供 DeepSeek 配置。填写自己的 API Key 和服务商支持的模型名称；API 服务地址默认是 `https://api.deepseek.com`。
6. 点击「保存设置」。可使用「保存并测试连接」发送一小段测试文字，测试会使用自己的模型额度。

也可解压 `si-translate-v0.2.0.zip` 后加载解压的文件夹；选择的文件夹中应直接包含 `manifest.json`。不要直接选择 ZIP。更新已有扩展时，在 `chrome://extensions` 点击思译卡片上的重新加载，再刷新网页；API Key 和模型设置保留。若 Chrome 提示访问权限变化，需要允许后才能在所有网站自动显示划词按钮。

DeepSeek 默认模型预设为 `deepseek-flash`，关闭推理以优先速度与成本。模型名称、可用性和参数以[服务商当前文档](https://api-docs.deepseek.com/)为准。如果使用自定义兼容接口，填写基础地址（例如 `https://your-provider.example/v1`）、API Key 和模型名称。JSON 输出模式仅在服务商支持时开启；不支持流式接口时可关闭流式响应。

## 日常使用

- **整页翻译**：选择目标语言与模型，点击「翻译此页」。先处理当前屏幕，再处理页面其他已加载内容；首次默认简体中文。
- **显示方式**：默认替换原文，随时可切换双语。双语译文附在原文字段后，保留链接与强调结构。
- **原文恢复**：点击「恢复原文」；网站在翻译期间自行更新的内容不会被旧原文覆盖。
- **停止与重试**：停止后保留已经完成的译文。出现失败时，可重试失败部分；希望重新翻译全部内容时，再点击「翻译此页」。
- **划词翻译**：默认在所有普通网站开启，无需逐站点击。弹窗显示当前网站实际保存的划词启用状态；可到设置页调整范围。选中文字只显示「译」按钮，点击后才发送请求。Esc 关闭浮层。
- **右键翻译**：不启用划词授权也可选中文字并使用右键「用思译翻译选中文字」。
- **快捷键**：`Alt+Shift+T` 翻译整页，`Alt+Shift+R` 恢复原文。快捷键若冲突，可在 `chrome://extensions/shortcuts` 调整。

修改默认目标语言或模型，不会改变已经运行的整页或视频任务。整页重新点击「翻译此页」会先恢复原文，再按当前配置翻译；视频需点击「重新开始」。

## 视频字幕（0.2.0）

1. 打开视频，选择目标语言与模型，点击弹窗中的「翻译视频字幕」。默认选择主页面最大的可见视频。
2. **标准 HTML5 视频**：使用播放器当前开启的字幕轨道，没有开启时尝试第一条字幕轨道。已有字幕提前翻译未来约 30 秒，倍速时调整预取范围，最多 90 秒；不一次发送整场视频。暂停、拖动和倍速变化都按播放器时间同步，回看复用会话缓存。
3. **YouTube 实验支持**：先在 YouTube 开启自带字幕，扩展读取播放器当前显示的字幕，变化稳定约 350 ms 后翻译。支持录播或直播中可显示的字幕，但不能提前读取整段字幕，响应慢时可能只显示原文。本版本未在真实 YouTube 网站上完成验证，页面结构变化可能影响适配。
4. 「同时显示原文」切换叠加层双语；关闭后在译文尚未完成或失败时仍保留原文。YouTube 网站原字幕保持不变，此开关只控制思译叠加层。「重试」处理失败字幕；「停止」取消任务、移除叠加层，并恢复扩展临时调整的字幕轨道状态。关闭工具栏弹窗不会停止视频字幕任务。

只有明确点击开启后才加载视频模块和发送字幕文字，不采集麦克风、标签页音频或视频画面，不新增音视频权限。字幕沿用已有模型配置、会话缓存与用量统计。只保留最多 240 个字幕工作项，单次最多 6 条，超时 15 秒取消；过期或切换视频后的结果不覆盖当前画面。

支持主文档可读取的 `TextTrack` 字幕及网页容器全屏。跨域 iframe 播放器、封闭 Shadow DOM、画中画、浏览器原生视频全屏、烧录在画面中的字幕和没有文字字幕的视频暂不支持。切换视频或字幕语言后重新开启。多字幕轨道时可先在原播放器选择语言，再开启翻译。无字幕音频识别和翻译配音属于后续阶段。

## 支持范围与行为

首版重点支持普通文章、文档、论坛、标题、列表、按钮文字、表格单元格及可读取的开放 Shadow DOM。模型同时处理多种语言，段落上下文参与翻译，已有目标语言内容要求保持原样。

整页翻译处理**主文档**的已加载、可读取文字；不自动滚动、不自动翻页。动态新增文字默认在本页已开始翻译后处理。默认单页最多 100,000 个源字符，可在设置中调整。代码、输入框、可编辑区域、隐藏内容以及 `translate="no"` 区域不会被整页翻译改动；用户主动选中的代码文字仍可划词翻译。

首版不做图片 OCR、Canvas、PDF、封闭 Shadow DOM 和 iframe 的整页遍历。已授权内嵌网页可以划词翻译；右键翻译优先在对应框架显示，访问受限时尝试在主页面显示。`chrome://`、Chrome 应用商店等浏览器限制页面不能注入扩展。虚拟列表及反复重建 DOM 的应用可能需要重新翻译；模型也可能误译，原文始终可恢复。

## 权限、数据与费用

- 0.1.1 为默认划词申请普通 HTTP/HTTPS 网站访问权限；Chrome 安装、更新或网站访问设置决定实际授权。可以在扩展设置中调整划词范围，或在 Chrome 中限制网站访问。
- 保存 API 地址不会发送网页内容。默认划词仅监听选区，在点击翻译按钮后才访问模型服务。
- API Key 保存在本机的扩展存储，仅扩展界面和后台可读取，不进入网页、不记录日志、不通过浏览器同步。
- 扩展直接访问配置的 API，没有中转服务器、账号系统或遥测。请求正文包含待翻译文字与必要上下文；划词的段落上下文默认关闭。
- 译文按段落缓存：恢复原文后再次翻译、滚动或请求重新分批，都可复用已译内容；只请求新增或变化的段落。原文、段落上下文、目标语言或模型不同会重新翻译。缓存仅在浏览器会话内保留，容量上限 4 MB，满时淘汰较久未使用的译文，可在设置中关闭或手动清除；缓存不保存密钥，重启浏览器或重新加载扩展后会清除。
- 全局最多 2 个模型请求同时进行；排队优先级为划词、视频字幕、整页翻译，不强行中断已经发送的请求。相同正在处理的批次可合并，取消一个页面不会取消其他页面仍需要的合并请求。
- 429 和 5xx 响应最多自动重试一次。0.2.0 检测输出长度截断、JSON 不完整或缺失片段时，将批次二分后有限重试，最多两层、7 次子请求；单个片段仍失败时保留原文，可手动重试。重复或非法 ID、认证失败不会因此重试。分批恢复可能增加费用，成功任务的用量包含这些已收到的响应。超时与网络断开不会自动重发可能已被服务商计费的请求。
- 本地用量只统计收到并校验成功的模型响应。配置单价时显示 USD 估算，不代表服务商账单；失败、取消和连接中断的请求也可能计费。
- 本机存储不提供硬件级密钥保护。可在设置中移除或修改密钥；翻译内容的保存政策由所配置的模型服务商决定。

## 开发与验证

运行时无第三方框架或 SDK；开发使用 TypeScript、Vite、Node.js 测试运行器与 Playwright。推荐 Node.js 22 以上、pnpm 11 以上。

```powershell
pnpm install
pnpm run check
pnpm run test
pnpm run build
pnpm exec playwright install chromium
pnpm run test:browser
```

若将测试浏览器安装在项目内部：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.test-browsers"
pnpm exec playwright install chromium
pnpm run test:browser
```

浏览器测试启动隔离配置，不修改日常 Chrome 数据，不调用真实模型。自动测试使用生产权限配置，页面和模型内容均来自本机模拟服务；YouTube 测试拦截站点 URL，返回本地播放器 fixture，不访问真实 YouTube 数据。截图、测试结果、构建体积和性能数据位于 `artifacts`。测试浏览器与开发依赖不包含在扩展安装包中。

源文件结构及后续字幕扩展方式见 [DESIGN.md](DESIGN.md)。验证结果与实际使用边界见 [VERIFICATION.md](VERIFICATION.md)。
