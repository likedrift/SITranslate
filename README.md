# 思译 · Si Translate

一个轻量的 Chrome Manifest V3 扩展。用你选择的大模型翻译整页、选中文字或视频字幕，保留页面功能，并可恢复原文。

## 安装与首次配置

已经构建好的扩展在本项目的 `dist` 文件夹，安装无需 Node.js 或其他开发工具。

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 `D:\haru_ws\si_translate\dist`。
4. 在工具栏固定「思译」，点击扩展，再点击设置按钮。
5. 默认提供 DeepSeek 配置。填写自己的 API Key 和服务商支持的模型名称；API 服务地址默认是 `https://api.deepseek.com`。
6. 点击「保存设置」。可使用「保存并测试连接」发送一小段测试文字，测试会使用自己的模型额度。

也可解压 `si-translate-v0.7.0.zip` 后加载解压的文件夹；选择的文件夹中应直接包含 `manifest.json`。不要直接选择 ZIP。更新已有扩展时，将新版文件覆盖到原来的扩展目录，在 `chrome://extensions` 点击思译卡片上的重新加载，再刷新网页；API Key 和模型设置保留。若 Chrome 提示访问权限变化，需要允许后才能在所有网站自动显示划词按钮。

DeepSeek 默认模型预设为 `deepseek-flash`，关闭推理以优先速度与成本。模型名称、可用性和参数以[服务商当前文档](https://api-docs.deepseek.com/)为准。如果使用自定义兼容接口，填写基础地址（例如 `https://your-provider.example/v1`）、API Key 和模型名称。JSON 输出模式仅在服务商支持时开启；不支持流式接口时可关闭流式响应。

## 日常使用

- **整页翻译**：选择目标语言与模型，点击「翻译此页」。先处理当前屏幕，再处理页面其他已加载内容；首次默认简体中文。
- **显示方式**：默认替换原文，随时可切换双语。双语译文附在原文字段后，保留链接与强调结构。
- **原文恢复**：点击「恢复原文」；网站在翻译期间自行更新的内容不会被旧原文覆盖。
- **停止与重试**：停止后保留已经完成的译文。出现失败时，可重试失败部分；希望重新翻译全部内容时，再点击「翻译此页」。
- **划词翻译**：默认在所有普通网站开启，无需逐站点击。弹窗显示当前网站实际保存的划词启用状态；可到设置页调整范围。选中文字只显示「译」按钮，点击后才发送请求。Esc 关闭浮层。
- **右键翻译**：不启用划词授权也可选中文字并使用右键「用思译翻译选中文字」。
- **快捷键**：`Alt+Shift+T` 翻译整页，`Alt+Shift+R` 恢复原文。快捷键若冲突，可在 `chrome://extensions/shortcuts` 调整。

修改默认目标语言或模型，不会改变已经运行的整页或视频任务。整页重新点击「翻译此页」会先恢复原文，再按当前配置翻译；视频需点击「重新开始」。

## 视频字幕（0.2.0）

1. 打开视频，选择目标语言与模型，点击弹窗中的「翻译视频字幕」。默认选择主页面最大的可见视频。
2. **标准 HTML5 视频**：使用播放器当前开启的字幕轨道，没有开启时尝试第一条字幕轨道。已有字幕提前翻译未来约 30 秒，倍速时调整预取范围，最多 90 秒；不一次发送整场视频。暂停、拖动和倍速变化都按播放器时间同步，回看复用会话缓存。
3. **YouTube 实验支持**：先在 YouTube 开启自带字幕，扩展读取播放器当前显示的字幕，变化稳定约 350 ms 后翻译。支持录播或直播中可显示的字幕，但不能提前读取整段字幕，响应慢时可能只显示原文。本版本未在真实 YouTube 网站上完成验证，页面结构变化可能影响适配。
4. 「同时显示原文」切换叠加层双语；关闭后在译文尚未完成或失败时仍保留原文。YouTube 网站原字幕保持不变，此开关只控制思译叠加层。「重试」处理失败字幕；「停止」取消任务、移除叠加层，并恢复扩展临时调整的字幕轨道状态。关闭工具栏弹窗不会停止视频字幕任务。

只有明确点击开启后才加载视频模块和发送字幕文字，不采集麦克风、标签页音频或视频画面，不新增音视频权限。字幕沿用已有模型配置、会话缓存与用量统计。只保留最多 240 个字幕工作项，单次最多 6 条，超时 15 秒取消；过期或切换视频后的结果不覆盖当前画面。

这一路线支持主文档可读取的 `TextTrack` 字幕及网页容器全屏。跨域 iframe 播放器、封闭 Shadow DOM、画中画、浏览器原生视频全屏、烧录在画面中的字幕暂不支持。切换视频或字幕语言后重新开启。多字幕轨道时可先在原播放器选择语言，再开启翻译。没有文字字幕的视频改用下方的实时语音路线；翻译配音尚未开发。

## 日语直播实时翻译（0.3.0）

无需 YouTube 自带字幕，采集当前标签页的声音，通过百炼流式识别日语，再使用现有文字翻译模型生成中文字幕。不需要运行中转服务器，不采集麦克风或视频画面。

### 开播前配置

1. 用 `si-translate-v0.7.0.zip` 的内容覆盖原扩展目录，在 `chrome://extensions` 点击思译「重新加载」。从 0.2.0 或更早版本升级会新增标签页音频、隐藏音频处理页及限定语音服务的 WebSocket 访问权限；若 Chrome 暂停扩展，需要允许更新权限后再刷新 YouTube。不要卸载旧扩展，以保留配置。
2. 保留现有文字翻译配置（DeepSeek 或兼容服务），目标选择「简体中文」。建议关闭推理，并先用「保存并测试连接」确认文字服务可用。
3. 点击弹窗「语音设置」，在「实时语音」填写自己的百炼 Key，默认模型 `qwen3-asr-flash-realtime`，直播语言「日语」。语音 Key 和文字模型 Key 分开保存。
4. 默认北京地址 `wss://dashscope.aliyuncs.com/api-ws/v1/realtime`。若 Key 在新加坡创建，改为 `wss://dashscope-intl.aliyuncs.com/api-ws/v1/realtime`；业务空间专用域名也可配置。Key 地域、模型开通和余额必须匹配。
5. 可在术语框填写日语人物名、节目名、作品名。点击「保存并测试语音连接」，成功表示握手与会话配置通过，不代表已识别真实日语。测试及修改配置会停止正在运行的音频翻译。
6. 今天先播放一段日语视频试用，检查声音、字幕和延迟，再用于直播。

### 观看时使用

回到 YouTube 直播页，播放视频并取消播放器静音，从 Chrome 工具栏打开思译，点击 **「开始实时翻译」**。工具栏出现「音」标记，字幕显示在视频上方；关闭插件小窗口后仍继续运行。原声以设备采样率播放，识别分支使用 16 kHz 单声道 PCM。

看完点击 **「停止音频」**。视频区的「停止」也会真正停止采集；切换到网站字幕路线会停止音频路线。刷新、关闭网页或拖动进度会结束采集，回到直播位置后重新点击开始。原生视频全屏与画中画不能叠加字幕，请使用网页播放器全屏或普通窗口。主页面找不到视频时使用窗口底部字幕，受限全屏 iframe 仍无法覆盖。

固定日语减少误判。服务端 VAD 默认仍以 600 ms 停顿分句；可在设置「实时语音」的「高级」里改为 400 或 800 ms。更短更灵敏，句子更碎；更长更稳，延迟更高。保存后需重新开始。优先在已确认文本的句末标点处分段，0.6.0 将长句上限从约 48 字缩至 36 字，并按逗号等边界拆分；尚未成句的稳定尾部至少 12 字、本地等待由约 2 秒缩至 800 ms；满 12 字后从该句首次出现或上次提交起算，到点即提交，不必再等下一秒的健康刷新。不提交 ASR 尚未确认的草稿。同一句话增长时复用已处理前缀，排队中的修订合并为最新版；同一发言末尾修订可以更新当前片段，不回放已经显示过的旧片段。长句拆分会携带前文帮助模型理解，但仍不能保证所有日语断句自然。

正在等待新译文时短暂保留上一条中文，不反复闪烁。弹窗显示最近一段的排队和翻译耗时，从已确认文本进入翻译流程时开始计时，**不包含音频采集、ASR 确认及播放器直播延迟**。实际总延迟受主播断句、网络和文字模型影响，没有受控真实端到端测量，不承诺固定秒数。听不清、重叠讲话、音乐和专有名词仍可能误识别。

仅允许一个音频会话、一个实时文字请求。排队中相邻的短片段（每段不超过约 36 字、合起来不超过约 72 字、产生时间相距不超过约 3 秒）会合成一次翻译，少发请求、少丢句子；合成后队列仍只保留最新三条。合并后的排队和过期都从这组里最早的片段算起，离得较远的新句不会和即将过期的旧句绑在一起跳过。同一 ID 的修订仍替换为最新文本。模型还是跟不上时，会整组跳过较早的待译内容，优先跟上直播，因此仍可能漏掉部分话语。排队超过约 12 秒，或结果回来时已超过约 15 秒，会提示并跳过。文字翻译超过约 12 秒会取消这一次请求，提示「已跳过，继续识别」；语音识别仍在进行，不必因此重新开始。不保存整场录音。开播或重连时，连接尚未就绪的声音最多保留约 2 秒，并在就绪当刻按顺序补发；停止和重连会丢掉更早的缓冲，断线空档不会整段补传。语音断线最多连续重连两次，稳定运行后重置重试预算。失败时显示提示，不无限重试。后台重启可恢复正在运行会话的文字配置。

语音识别和文字翻译分别计费；弹窗显示采集时长，不代表服务商账单。暂停视频、静音或无人说话仍可能保持连接并产生语音费用，离开前请停止。语音费用不包含在原有文字 Token 统计里。

协议依据：[百炼 ASR 客户端事件](https://www.alibabacloud.com/help/en/model-studio/qwen-asr-realtime-client-events)、[服务端事件](https://www.alibabacloud.com/help/en/model-studio/qwen-asr-realtime-server-events)、[Chrome 标签页音频](https://developer.chrome.com/docs/extensions/reference/api/tabCapture)。

## Qwen-Audio 3.1 Streaming（0.5.0）

支持 `qwen-audio-3.1-asr-flash-streaming`，同时保留原来的 `qwen3-asr-flash-realtime`。升级不会自动替换已保存的模型，也不修改文字翻译配置。

1. 更新扩展并刷新直播页，进入设置「实时语音」。
2. 将「识别模型」填为 `qwen-audio-3.1-asr-flash-streaming`（输入框也提供候选）。
3. 选择 Key 所属地域（北京或新加坡），填写该 Key 所属业务空间的 **Workspace ID**，从百炼该地域的业务空间详情复制。地址会自动生成，也可以直接粘贴完整业务空间地址：
   - 北京：`wss://你的WorkspaceID.cn-beijing.maas.aliyuncs.com/api-ws/v1/inference`
   - 新加坡：`wss://你的WorkspaceID.ap-southeast-1.maas.aliyuncs.com/api-ws/v1/inference`
4. 保留匹配该地域和业务空间的百炼 Key，直播语言选日语；3.1 的术语上下文最多 400 字。点击「保存并测试语音连接」。测试成功仅确认连接与任务参数。
5. 回到 YouTube，从工具栏点击「开始实时翻译」。字幕拖动、外观、分句去重和文字翻译模型继续沿用现有功能。

切回原模型时，将模型改为 `qwen3-asr-flash-realtime`，地址自动改为 `/api-ws/v1/realtime`，保存后重新开始。两个模型共用语音 Key、语言和术语配置；更换地域或业务空间时请同时使用匹配的 Key。

3.1 使用独立 Inference WebSocket 协议，等待 `task-started` 后发送 16 kHz 单声道 PCM16 二进制帧；不会把旧版 `session.update` 协议发送给新模型。中间结果按同一句子的快照处理，只提前翻译 `words.fixed=true` 的连续稳定前缀；没有稳定标记时先预览原文，等待最终句子再翻译。默认仍使用 600 ms VAD，并与原模型共用同一档位；现有分句规则不变。没有启用文档存在差异、尚未实测的语义断句参数。仅保存最新句级时间戳用于后续同步，不进行整场录音或转写历史存储。

弹窗单独显示服务端已返回的累计语音输入/输出 Token；重复累计值不重复相加，重连后的新任务合并计数。停止时立即关闭音频与连接，可能收不到最终用量，所以此数值不是最终账单，也不计入文字翻译 Token。原模型的按秒计费仍以服务商账单为准。真实日语质量、费用和延迟需要试播比较，未因模型版本更高而自动设为默认。

协议依据：[WebSocket 地址与交互](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-streaming-websocket-api)、[客户端事件](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-streaming-client-events)、[服务端事件](https://help.aliyun.com/zh/model-studio/qwen-audio-asr-streaming-server-events)。

## 渐进译文、阅读与延迟诊断（0.6.0）

原来“语音识别是流式、中文字幕却整句出现”，主要因为文字模型的 SSE 虽然已读取，直播通道只在最终 JSON 校验完成后发送译文；新句完成时也会立即覆盖旧句。现在只解码当前片段的 text，约每 80 ms 合并更新一次字幕，最终结果仍完整校验。显示“生成中”表示暂定译文；失败或服务过滤时撤回，保留较早的完整译文。若这段译文已经流式上屏，但从片段产生起超过约 15 秒才结束，会记为过期并撤回暂定字幕，阅读可以继续，而不会一直停在「生成中」。不会用打字动画伪装流式，也不将 JSON、推理内容作为译文。

**文字模型设置必须开启「流式响应」**；尊重用户原本关闭的设置，关闭时仍整段显示。ASR 也是中间/最终快照，服务端不保证逐字发送；3.1 不提供 fixed 稳定前缀时，日语可以先预览，中文仍需等待最终识别后开始生成。没有把未确认草稿逐字送模型，以免修订导致误译、闪烁及重复费用。

字幕上方保留上一条译文的末页，工具条支持「暂停字幕滚动」、上一条/下一条和「回到最新」。只暂停显示滚动，音频采集与翻译仍继续、仍可能计费；按钮旁会注明「暂停滚动仍在采集和计费」。最多保存 8 条临时字幕，当前句之后最多 3 条；暂停久了不会保存整场历史。

拖动进度、刷新页面或切换视频会停止采集。字幕上会短暂提示，弹窗状态也会写明需要重新点击「开始实时翻译」。手动点击停止则立即收起字幕。若当前文字模型关闭了「流式响应」，弹窗的实时语音区会提示：字幕要等整段译完，延迟会更高。

「字幕位置与显示」新增节奏选择：默认「阅读优先」，按字数保留当前句并给最终文字短暂阅读时间，对新句最多额外等待约 2.5 秒；过期排队项会跳过以跟上直播。「实时优先」立即切到新句，上一条和回看仍可用。长字幕可分页，暂停滚动时也暂停自动翻页。实时性与阅读时间存在取舍，不能保证快语速下每句都完整读完。

展开弹窗「本地延迟诊断」查看最近 100 个片段的 P50/P95 和样本数，可导出 JSON 或清除：

| 指标 | 测量范围 |
| --- | --- |
| 识别返回（估算） | 上传音频帧映射到 ASR 稳定部分/整句末尾时间戳后，至收到相应识别事件 |
| 本地组句 | 最近一次识别结果收到后，至提交该翻译片段 |
| 待译排队 / 模型调度 | 本地文字队列，及后台权限/缓存/记账等等待。直播不再排队等待整页占满的两个共享槽 |
| 首 Token / 首段译文 / 译文完成 | 实际开始模型调用后，分别收到首个 content、可显示文字、完整结果；首 Token 可能只是 JSON 前缀 |
| 显示缓冲 / 提交到上屏 | 进入显示队列后，以及翻译片段提交后，至可见页面的首次显示估算 |
| 句末到上屏（估算） | ASR 音频末尾时间戳映射到首次显示；只在能映射时间戳时提供 |

上屏用可见页连续两次 requestAnimationFrame 估算，非硬件呈现时间。音频帧时钟只保留最近约 30 秒数字元数据，误差包含 100 ms 分帧、线程调度等；不包含 YouTube/CDN 的直播延迟。默认模型 `qwen3-asr-flash-realtime` 使用 `input_audio_buffer.speech_stopped` 的 `audio_end_ms` 估算识别返回和句末到上屏；时间戳缺失或无法映射到已上传音频时不计，**未知不填 0**。缓存命中与模型非流式可从样本区分。诊断只在本机浏览会话内保存数字耗时、长度、状态及随机样本 ID，不含原文、译文、音频、Key、模型地址或网页 URL，不上传。导出由用户点击触发，并带上 outcome 计数（completed、failed、stale、skipped、cancelled、pending）以及识别模型名、语言、文字模型名、是否流式、阅读节奏、目标语言和固定队列策略（短片段合并后最多约 3 条、约 12 秒跳过、约 15 秒过期）。策略里另有当前服务端 VAD 静默档位 `silenceDurationMs`（默认 600）。不含 Key、接口地址、术语或原文译文。

## 字幕位置与显示（0.7.0）

- 直接按住字幕条的文字或空白处拖动；四角有缩放手柄，可分别调整宽度和高度，对角保持固定。翻页、暂停、回看等按钮仍正常点击。Esc 可取消正在进行的拖动或缩放。
- 也可使用上方「拖动字幕」手柄；Tab 聚焦手柄或四角后，方向键微调移动或尺寸，Shift 加快。尺寸调整不改变设定字号，文字会重新换行、分页；最小尺寸以容纳当前文字与控件为限，不裁掉内容。拉高增加字幕条留白。
- 弹窗展开「字幕位置与显示」，调整字号（14～40 px）、宽度、背景不透明度。默认限制在视频范围，选择「整个页面」后可放到页面其他位置。
- 普通窗口与网页全屏分别保存位置和尺寸；重新开始、重开弹窗或刷新后重新开启字幕仍使用已保存的布局。保存的是范围内相对坐标和尺寸比例，调整窗口大小时会限制字幕位置，避免越界。
- 「锁定字幕位置和尺寸」隐藏所有手柄并禁用主体拖动；「恢复默认位置与显示」清除两套布局并恢复外观。宽度滑块恢复按百分比自动布局，同时清除两套手动尺寸；调整字号、透明度、节奏或锁定会保留手动尺寸。显示调整立即生效，不发送模型请求，不清空文字缓存。
- 「同时显示原文」对网站字幕和实时字幕共用并记忆。工具栏弹窗和设置页「阅读偏好」写入同一项。译文未就绪或失败时仍显示原文。长字幕分页显示，支持上一页、下一页及自动翻页；新片段到来时优先显示新片段，不积攒历史字幕等待看完。原文和译文按各自长度分页，不保证逐页逐词对齐。

## 回退版本

本机保留 `si-translate-v0.6.0.zip` 与更早版本；仓库标签 `v0.6.0` 对应加入主体拖动与四角缩放前的版本，新包为 `si-translate-v0.7.0.zip`。回退到 0.6.0 保留现有识别和翻译配置；旧版忽略手动尺寸。

1. 在弹窗停止实时音频翻译。回退到 0.5.0 可保留 3.1 配置；如果降至 0.4.0 或更早版，先在语音设置切回 `qwen3-asr-flash-realtime` 并保存，使地址恢复 `/realtime`，这些更早版本不能识别新模型名和 `/inference` 地址。
2. 将旧版 ZIP 解压，使用其中的文件覆盖**当前已加载扩展的同一个目录**（例如 `dist`）；不要加载到另一个目录或卸载扩展，以免产生另一份配置。
3. 在 `chrome://extensions` 点击思译「重新加载」，再刷新直播网页。

0.4.0 没有迁移或删除模型、Key 和语音配置；新增的 `captionLayout` 独立保存，0.3.0 会忽略它。回退时会话缓存会重置。开发者可从标签重新构建旧版；若要回退主分支的改动，使用新的 revert 提交保留仓库历史，不强推。

## 支持范围与行为

首版重点支持普通文章、文档、论坛、标题、列表、按钮文字、表格单元格及可读取的开放 Shadow DOM。模型同时处理多种语言，段落上下文参与翻译，已有目标语言内容要求保持原样。

整页翻译处理**主文档**的已加载、可读取文字；不自动滚动、不自动翻页。动态新增文字默认在本页已开始翻译后处理。默认单页最多 100,000 个源字符，可在设置中调整。代码、输入框、可编辑区域、隐藏内容以及 `translate="no"` 区域不会被整页翻译改动；用户主动选中的代码文字仍可划词翻译。

首版不做图片 OCR、Canvas、PDF、封闭 Shadow DOM 和 iframe 的整页遍历。已授权内嵌网页可以划词翻译；右键翻译优先在对应框架显示，访问受限时尝试在主页面显示。`chrome://`、Chrome 应用商店等浏览器限制页面不能注入扩展。虚拟列表及反复重建 DOM 的应用可能需要重新翻译；模型也可能误译，原文始终可恢复。

## 权限、数据与费用

- 0.1.1 为默认划词申请普通 HTTP/HTTPS 网站访问权限；Chrome 安装、更新或网站访问设置决定实际授权。可以在扩展设置中调整划词范围，或在 Chrome 中限制网站访问。
- 保存 API 地址不会发送网页内容。默认划词仅监听选区，在点击翻译按钮后才访问模型服务。
- API Key 保存在本机的扩展存储，仅扩展界面和后台可读取，不进入网页、不记录日志、不通过浏览器同步。
- 扩展直接访问配置的 API，没有中转服务器、账号系统或遥测。文字请求包含待翻译文字与必要上下文；划词的段落上下文默认关闭。实时语音开启后，标签页音频直接发送到所配置的百炼服务。
- 译文按段落缓存：恢复原文后再次翻译、滚动或请求重新分批，都可复用已译内容；只请求新增或变化的段落。原文、段落上下文、目标语言或模型不同会重新翻译。缓存仅在浏览器会话内保留，容量上限 4 MB，满时淘汰较久未使用的译文，可在设置中关闭或手动清除；缓存不保存密钥，重启浏览器或重新加载扩展后会清除。
- 全局最多 2 个模型请求同时进行；排队优先级为划词、视频字幕、整页翻译，不强行中断已经发送的请求。相同正在处理的批次可合并，取消一个页面不会取消其他页面仍需要的合并请求。
- 429 和等价限流（错误体里的 rate limit、throttling）先等待约 2 秒，再自动重试一次。直播里若仍然限流，下一段翻译会再等一会儿（连续时约 4 秒，最多约 8 秒），避免失败后立刻打出下一句。其他 5xx 仍最多自动重试一次，间隔约 1.5 秒。0.2.0 检测输出长度截断、JSON 不完整或缺失片段时，将批次二分后有限重试，最多两层、7 次子请求；单个片段仍失败时保留原文，可手动重试。重复或非法 ID、认证失败不会因此重试。分批恢复可能增加费用，成功任务的用量包含这些已收到的响应。超时与网络断开不会自动重发可能已被服务商计费的请求。
- 本地用量只统计收到并校验成功的模型响应。配置单价时显示 USD 估算，不代表服务商账单；失败、取消和连接中断的请求也可能计费。
- 本机存储不提供硬件级密钥保护。可在设置中移除或修改密钥；翻译内容的保存政策由所配置的模型服务商决定。

## 开发与验证

运行时无第三方框架或 SDK；开发使用 TypeScript、Vite、Node.js 测试运行器与 Playwright。推荐 Node.js 22 以上、pnpm 11 以上。

```powershell
pnpm install
pnpm run check
pnpm run test
pnpm run build
pnpm exec playwright install chromium
pnpm run test:browser
pnpm run test:speech
```

若将测试浏览器安装在项目内部：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\.test-browsers"
pnpm exec playwright install chromium
pnpm run test:browser
```

浏览器测试启动隔离配置，不修改日常 Chrome 数据，不调用真实模型。自动测试使用生产权限配置，页面和模型内容均来自本机模拟服务；YouTube 测试拦截站点 URL，返回本地播放器 fixture，不访问真实 YouTube 数据。截图、测试结果、构建体积和性能数据位于 `artifacts`。测试浏览器与开发依赖不包含在扩展安装包中。

语音自动验证全程无声：隔离浏览器强制静音，真实采集只发送静音帧；非零信号的重采样、混音和分帧使用不连接扬声器的 OfflineAudioContext，PCM16 编码另由核心测试验证。不生成蜂鸣声，不调整系统或日常浏览器的音量。不得为补充验证解除测试浏览器静音。

源文件结构及后续字幕扩展方式见 [DESIGN.md](DESIGN.md)。验证结果与实际使用边界见 [VERIFICATION.md](VERIFICATION.md)。
